## 已核实的口径问题
直接读取正式h5ad的obs编码得到：
- L1实际16类。
- 正式命名L2为116种；另有Unknown和Not_assessed，原始level2_annotation共118个不同值。
- 按L1父类组合后为128个分析组：116个命名状态+12个父类限定的未解决/未评估组。
因此“128个正式稳定L2状态”不成立。空间128 factors、某些下游128组、遗传103个合资格L2组、CoVarNet89个节点各有自己的定义，不能互换。
同样，247 sample_uid、229个L1通讯生物样本、212个L2通讯合资格样本、223个网络profiles、217个网络疾病关联profiles不是相同统计单位/纳入范围。
